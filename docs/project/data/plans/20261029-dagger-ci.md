# Run the flake checks with Dagger

## Context

The user asked for Dagger CI at its latest version (the 1.0 beta) on this
repository: run the checks locally, run them again to see the cache, then have
Dagger Cloud run them after each push. nixbot stays the gate; Dagger reports
beside nix-ci, as `docs/delivery/dagger.md` describes.

## Approach

A Dagger workspace (`dagger.toml`) installs one Dang module, `flake`, that
exposes `checks.x86_64-linux` as a collection keyed by attribute name, so
`dagger check --flake-check=NAME` selects one. A batch `build` runs the selected
checks in one `nix-fast-build --skip-cached` run in a `nixos/nix` container,
which keeps evaluation memory bounded and matches the luvus gate. `/nix` and
Nix's fetcher cache are cache volumes seeded from the image. Dagger's
content-keyed cache skips the run when the source is unchanged. Builds use the
workstation's `max-jobs` and `cores`, and a `homelab` env overlay adds the
tailnet cache for local runs, which Cloud Checks cannot reach.

Rejected: one container per flake check without a batch function. Each would
evaluate the flake separately, and seven NixOS evaluations in parallel would
outgrow the laptop's 16 GiB. Rejected: a GitHub Actions workflow calling
`dagger check`. Cloud Checks need no workflow file and keep a warm cache.

- [x] Package the 1.0.0-beta.21 release binary, since nixpkgs has none; expose
  it as `packages.dagger`, in the dev shell, and in the workstation home, with a
  `nixpkgs-watch` entry.

### Task 2: Workspace and module

- [x] `dagger init`, install `dagger.io/sdk/dang`, and write the `flake` module.
- [x] `docs/delivery/dagger.md`, and a line in `AGENTS.md`.

### Task 3: Local runs

- [x] Run `dagger check` cold, then again on a changed tree and an unchanged
  one. All checks passed each time. Cold: 20m19s, mostly compiling jj-graph and
  the home's Rust packages, which no public cache holds. After editing docs and
  settings: 1m24s, rebuilding only `den-inventory-tests`, which reads the whole
  source. Unchanged: 5s, the `nix-fast-build` exec served from cache.
  `whitespace` passed as cached every time: its runCommand never reads the
  repository.

### Task 4: Cloud Checks (the user)

- [ ] Sign in to Dagger Cloud, connect GitHub, and run `dagger cloud checks on`.
- [ ] Push a branch that carries `dagger.toml` and watch
  `dagger cloud checks list --watch`.

### Task 5: Delivery

- [ ] Deliver through luvus, so every branch carries the workspace.
